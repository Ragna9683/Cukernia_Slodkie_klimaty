# Cukiernia & Pracownia Tortów — Projekt Komercyjny

Nowoczesna, wysokokonwersyjna koncepcja strony internetowej zaprojektowana dla rzemieślniczej cukierni. Projekt łączy w sobie apetyczny, świeży design (Fresh & Sweet UI) z zaawansowaną interaktywnością.

## 🍰 O projekcie
Głównym celem witryny jest automatyzacja procesu zamawiania tortów okolicznościowych oraz profesjonalna prezentacja wypieków. Zastosowano tu koncepcję "Color Pacing", która dzięki delikatnym pastelowym tłom (Vanilla & Blush) zmniejsza zmęczenie wzroku i buduje klimat premium.

### Główne funkcjonalności (Features):
* **Interaktywny Kalkulator Tortu:** Autorski suwak pozwalający klientowi dobrać wagę tortu do liczby porcji i natychmiast poznać szacunkowy koszt.
* **Wysuwany Drawer z Formularzem:** Panel zamówienia zintegrowany z kalkulatorem, zabezpieczony systemem antyspamowym (Honeypot).
* **Katalog & Galeria (Lightbox):** Kategoryzacja wypieków za pomocą zakładek (Tabs) oraz galeria zdjęć z efektem przyciemnienia tła (Backdrop-filter blur).
* **Moduł FAQ z wyszukiwarką:** Dynamiczny akordeon z polem natychmiastowego wyszukiwania (Instant Search) ułatwiający znalezienie informacji o dostawie czy zadatku.
* **Dynamiczny system opinii:** Skrypt JS przygotowany do zliczania i wyświetlania ocen ze średnią arytmetyczną.

## 🛠️ Stack technologiczny
* **HTML5:** Semantyczna struktura, mikrodane LocalBusiness.
* **CSS3:** Custom Properties, CSS Grid, Flexbox, zaawansowane gradienty.
* **JavaScript (Vanilla):** Canvas API (pływające cząsteczki), logika kalkulatora, walidacja formularzy, obsługa modali.
